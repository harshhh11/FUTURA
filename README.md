# FUTURA — Cinematic Financial Operating System
> **Disciplined Investing & Financial Planning for Tier-1 Students & First-Time Investors**

FUTURA is a high-performance, mobile-first financial planning application engineered with a cinematic, dark metallic aesthetic (near-black `#090A0C`, brushed silver, graphite, and muted champagne-gold `#D5B477`).

---

## ✨ Features & Architecture

### 1. 🪙 3D Floating Metallic Vault Card
- Realistic 3D perspective with brushed silver highlights and sharp diagonal specular reflection seam.
- Dynamic finish cycling (Silver, Champagne Gold, Obsidian Black).
- Direct quick top-up and card allocation workflows.

### 2. 📊 Total Wealth & Portfolio Analytics
- Real-time simulated wealth calculation:
  - **Cash & Savings** (`₹1,00,000` · 28%)
  - **Investments** (`₹2,35,720` · 66%)
  - **Emergency Buffer** (`₹21,000` · 6%)
  - Total: **₹3,56,720**
- Interactive SVG Mountain Curve Line Chart with monthly/annual timeframes and highlighted valuation tooltips.

### 3. 🎯 Budget & Savings (Open-Ring Visualization)
- 210° custom SVG horseshoe arc visualizer with 5-stage progressive reveal sequence.
- Envelopes: Essentials (Silver), Food (Gold), Transportation (Slate), Entertainment (Platinum), Savings (Mint).
- Interactive savings goals (New Laptop, Emergency Fund, Travel Fund) with progress tracking and contribution actions.

### 4. 📜 Ledger & Grouped Transactions
- Date-grouped audit log (Today, Yesterday, Earlier this month).
- Search and category filtering (`All`, `Contribution`, `Savings`, `Investment`, `Goal`).
- Real-time income, expense, and contribution arithmetic synchronized with user cash balance.

### 5. 🎛️ 4-Square Grid Feature Launcher
- Native mobile navigation drawer with 11 destinations across 4 groups:
  - **Core Planning**: Overview Dashboard, Smart MoneyFlow, Goal Simulator
  - **Investments**: Investment Explorer, Side-by-Side Compare, Portfolio Builder
  - **Resilience & Stress Test**: Bad-Year Rehearsal, Recovery Scenarios
  - **Records & Growth**: Transactions & Log, Financial Learning Hub, Profile & Settings

### 6. 🌊 Translucent Fade Floating Dock
- Floating capsule dock with smooth dark vertical gradient fade and backdrop blur.
- Pinned circular navigation buttons (`Home`, `Transactions`, `Plan`, `Profile`).

## 🚀 Quick Start

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm`

### Installation
```bash
# Clone the repository
git clone https://github.com/harshhh11/FUTURA.git

# Navigate to project folder
cd FUTURA

# Install dependencies
npm install

# Start development server
npm run dev
```

Open `http://localhost:5173` in your browser.

### Production Build
```bash
npm run build
npm run preview
```

## 🛠️ Tech Stack
- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS + Custom Shimmer Keyframes
- **Icons**: Lucide React
- **Audio Engine**: Web Audio API Procedural Synthesizer
- **State Management**: React Context + LocalStorage Persistence
